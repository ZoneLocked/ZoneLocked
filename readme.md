# 🔒 ZoneLocked

**ZoneLocked** is a World of Warcraft addon that transforms the game into a survival-style progression challenge. Zones start locked — and must be earned. Whether you level up, farm materials, or use WoW Tokens, the world becomes something you **unlock**, not something you race through.

---

## 🔓 Unlock Modes

Choose your playstyle:

- **Skill Mode** – Earn tokens by leveling your character or professions.
- **War Effort Mode** – Farm faction items to unlock zones (great for Classic & Hardcore).
- **Token Mode** – Spend one WoW Token per unlock (Retail only).
- **Manual Mode** – Mark zones as complete manually when you're ready.
- **ATT Mode** _(Optional)_ – Unlock a zone by 100% completing it in [All The Things](https://www.curseforge.com/wow/addons/all-the-things).
- **Random Unlock** _(Toggle)_ – Enable a lootbox-style spinner to determine the next zone when redeeming tokens.

---

## 🗺️ Features

- ✅ Zone-based lockout system with visual **map overlays**
- ✅ Per-character saved progression
- ✅ Full **in-game UI** with:
  - Mode selector
  - Zone unlock tracker
  - Skill & token progress
  - Settings and reset tools
- ✅ Floating token button when tokens are available
- ✅ Compatible with both **Retail** and **Classic** versions
- ✅ No external dependencies — lightweight and self-contained

---

## 🧪 Slash Commands

| Command             | Description                             |
| ------------------- | --------------------------------------- |
| `/zl` or `/zl open` | Open the main ZoneLocked UI             |
| `/zl mode`          | Change your unlock mode                 |
| `/zl bank <name>`   | Set your gold sink alt (Easy Mode)      |
| `/zl redeem [x]`    | Redeem tokens manually                  |
| `/zl reset`         | Reset progress and clear unlocked zones |
| `/zl random`        | Toggle random zone unlock on/off        |
